# RST guide の移行案内

従来の記述規則は、責務ごとに次の正本へ移した。

- [共通 RST guide](rst-core-style-guide.md): 文書構造、ラベルと参照、表・リスト、インライン記法、4段階の静的検査
- [MaatLog profile](profiles/maatlog.md): 文体・句読点、概要と以上、出力先・用語集、コード・図、MaatLog の検査方針

執筆時は先に [入力仕様](profile-interface.md) と [文書種別表](document-types.md) を確認する。
従来の procedure / explanation / operational は MaatLog として利用できる。
テンプレートは `assets/maatlog/` へ移動済みである。旧 asset パスは残していないため、種別表のリンクから読む。
