キューの振る舞い
================

キュー は到着した処理を順に保持する。
ワーカーは キュー から先頭の処理を取り出す。

キュー の状態遷移
-----------------

図は キュー の状態遷移を示す。

.. code-block:: python

    queue = ["a", "b"]
    queue.append("c")

待機中の表示例 ::

    queue: 2 pending

コマンドは ``queue`` サブコマンドを使う。
