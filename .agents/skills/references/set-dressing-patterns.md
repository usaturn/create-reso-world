# Set-Dressing Patterns

## Narrative clusters

Start with a specific event or habitual use, then select a small set of objects whose positions and state support it: a meal left mid-task, a rushed departure, a maintained workbench or an interrupted repair. Add only a few surface cues that reinforce the same cause. A cluster should read as a relationship, not a pile of individually interesting props. Stop adding when the beat is clear.

## Density and negative space

- Keep focal or interaction areas intentional: objects should clarify use, not compete with the focal item.
- Place supporting clusters in the midground to explain occupation or history.
- Use sparse background silhouettes where detail will not read.
- Leave clear negative space around important forms and between clusters. Empty space gives each group visual weight and lets its story register.
- Avoid uniform clutter across every shelf, wall and floor. Repetition is useful only when it communicates a pattern or activity.

## Travel and sightlines

Keep doors, stairs, openings and intended routes clear. Check the dressed scene from expected viewpoints so props do not obscure navigation cues, block access or create accidental collision hazards. Resolve route and collider questions in the owning world workflow; this reference guides prop placement, not world orchestration.
